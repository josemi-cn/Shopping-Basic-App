# Shopping-Basic-App

**"Shopping Basic App"** (or **"SBA"**) is a collection of apps that serve as base to develop shopping services.

This collection will include:
- Server
- Front-End Management App (or "Master App")
- Front-End Web
- Front-End Mobile App

## Server

This program is developed with Python/Flask and SQLite.

The core of the service, includes product management, command systems. (More could be added in the future)\
For more safety, it has a small user system based on roles. (Permission system will be added in the future)

## Master App

This program is developed with Python.

It serves to facilitate the management of the server through a simple UI. Functionalities change depending on your permissions.

## Front-End Web

This program is developed with React.

In this millenia, presence on the internet is vital, so in order to do so i bring you a web that will connect you with your customers.

## Front-End Mobile App

This program is developed with Kotlin.

Mobile phones are everywere this days, and the competition is already exploiding this. To help you even the odds i included an app for Android that will bring you to everyones phones.
